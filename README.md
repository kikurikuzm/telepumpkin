# IMPORTANT! 
### Interested in trying out the game?
Heres some simple instructions:
1. Download the *standard* release of [Godot 4.4](https://godotengine.org/download/archive/4.4-stable) (for this branch specifically)
2. Download the repository however you please (as a zip, through git, or some other way)
3. Run Godot and open the `.project` file from this repository
4. Once you've loaded the project into Godot, all you have to do is press **F5** (the default 'start whole game' keybind in Godot) and you should be up and running!
### Other stuff
Do keep in mind that this is a working branch, and you may encounter broken and unfinished things while playing.<br><br>
***You may also encounter story/gameplay spoilers, in commit messages and in-game! You've been warned!***
